# paper_processor 文献处理工具集

本仓库包含两个核心工具，用于批量处理学术文献，通过AI驱动实现元数据提取、翻译、总结等功能，并支持结构化Excel输出：

1. **pdf_processor**  
   基于Python Tkinter的GUI应用，专注于批量处理PDF格式学术论文，支持元数据提取、内容翻译与总结。  
   详细说明：[pdf_processor 文档](pdf_processor/README.md)

2. **LitIntel Agent**  
   功能更全面的AI驱动文献处理工具，支持PDF文件夹和PubMed导出TXT文件两种输入模式，提供增强型AI处理与配置功能。  
   详细说明：[LitIntel Agent 文档](LitIntel Agent/Readme.md)
