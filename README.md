# paper_processor 文献处理工具集

本仓库包含两个核心工具，用于批量处理学术文献，通过AI驱动实现元数据提取、翻译、总结等功能，并支持结构化Excel输出：

1. **pdf_processor**  
   基于Python Tkinter的GUI应用，专注于批量处理PDF格式学术论文，支持元数据提取、内容翻译与总结。  
   详细说明：[pdf_processor 文档](pdf_processor/README.md)

2. **LitIntel Agent**  
   功能更全面的AI驱动文献处理工具，支持PDF文件夹和PubMed导出TXT文件两种输入模式，提供增强型AI处理与配置功能。  
   详细说明：[LitIntel Agent 文档](LitIntel%20Agent/Readme.md)

3. **LitIntel Agent V2.0**
    * LitIntel Agent的升级款。
    * 一款强大的二合一GUI工具，不仅具备批量处理PDF或TXT文献并生成结构化Excel数据的功能，还能基于这些数据，利用AI自动生成专业的文献综述大纲和完整的HTML格式综述报告。
    * 详细说明：[Literature AI Processor 文档](./literature_ai_processor/README.md)
