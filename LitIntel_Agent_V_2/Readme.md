# LitIntel Agent V2.0(文献智能处理工具V2.0)

一款基于 Python 和 Tkinter 构建的桌面应用程序，旨在将研究人员从繁琐的文献整理与综述撰写工作中解放出来。它集成了强大的大语言模型（LLM）能力，提供了一个从原始文献到结构化数据，再到完整综述报告的一站式解决方案。

## 核心功能

本工具主要包含两大核心工作流：

1.  **文献批量处理**：
    * **多种输入源**：支持批量处理整个文件夹内的 `PDF` 文件，或处理单个包含多篇文献摘要的 `TXT` 文件（兼容PubMed数据库的导出格式）。
    * **智能信息提取**：自动从每篇文献中提取关键元数据，如标题、作者、期刊、发表年份、DOI等。
    * **AI翻译与总结**：调用AI模型将标题和摘要翻译为中文，并生成简明扼要的核心观点总结与结论。
    * **结构化输出**：将所有处理后的信息整齐地保存到一个 `Excel (.xlsx)` 文件中，便于后续分析和筛选。

2.  **AI辅助综述生成**：
    * **主题驱动**：用户只需提供一个研究主题和由第一步生成的文献Excel表。
    * **自动生成大纲**：AI能够根据所提供的文献数据，为指定主题自动生成一份逻辑清晰、结构合理的综述引言大纲。
    * **一键生成完整综述**：在用户确认或修改大纲后，AI将根据大纲要求和文献数据，撰写一篇包含正文、APA格式文中引用和标准参考文献列表的完整综述报告。
    * **HTML格式导出**：最终的综述报告将以一个排版简洁、浏览器友好的 `HTML` 文件形式保存。

## 技术栈与依赖

* **GUI框架**: `Tkinter`
* **核心库**: `pandas`, `openai`, `pypdf`, `httpx`
* **Excel处理**: `openpyxl`

## 安装与配置

1.  **克隆或下载代码**：
    将本项目代码下载到本地。

2.  **安装依赖库**：
    打开终端或命令行，进入项目目录，然后运行以下命令安装所有必需的Python库：
    ```bash
    pip install pandas openai pypdf httpx openpyxl
    ```

3.  **运行程序**：
    直接运行主Python脚本文件即可启动GUI应用。
    ```bash
    python your_script_name.py
    ```

4.  **初次配置**：
    * 首次启动时，程序会在同目录下生成一个 `config.json` 文件。
    * 请在GUI界面的 **“1. 基础配置”** 区域填入您的AI服务信息：
        * **API密钥**: 有效API Key。
        * **服务地址**: API的Base URL，仅支持兼容OpenAI的模型服务。
        * **模型名称**: 点击“刷新”按钮从服务地址自动获取可用模型列表，然后选择一个。
        * **网络代理** (可选): 如果您需要通过代理访问API，请勾选并填写正确的代理地址（如 `http://127.0.0.1:7890`）。
    * 关闭程序时，当前配置会自动保存到 `config.json` 文件中，方便下次使用。

## 使用指南

### 处理文献 (PDF/TXT -> Excel)

1.  在 **“1. 基础配置”** 部分完成AI服务设置。
2.  在 **“2. 文献处理”** 部分：
    * 点击 **“PDF文件夹”** 或 **“TXT文件”** 按钮，选择您的输入源。
    * 程序会自动生成一个默认的输出文件名，您也可以点击 **“另存为”** 自定义。
    * 根据需要勾选 **“翻译标题和摘要”**。
3.  点击 **“开始文献处理”** 按钮，程序将在后台开始运行。您可以在右侧的“运行日志”窗口查看实时进度。
4.  任务完成后，您会得到一个包含所有文献结构化信息的Excel文件。

### 生成综述 (Excel -> HTML)

1.  在 **“3. 主题综述”** 部分：
    * 输入您要撰写的 **“综述主题”**。
    * 点击 **“浏览...”** 按钮，选择上一步生成的文献Excel文件作为 **“文献源文件”**。
    * 指定一个 **“综述输出路径”**，用于保存最终的HTML报告。
2.  (可选) **生成大纲**：
    * 点击 **“AI生成大纲”** 按钮。AI会根据文献数据，在右上方的“综述大纲”文本框中生成一份建议大纲。
3.  **确认或修改大纲**：
    * 您可以在“综述大纲”文本框中直接编辑AI生成的大纲，或完全写入自己的大纲和写作要求。**（注意：此处的文本将作为最终生成综述的核心指令）**
4.  **生成综述**：
    * 确认大纲无误后，点击 **“开始生成综述”** 按钮。
    * AI将根据您的主题、文献数据和最终确定的“综述大纲”来撰写完整的报告。
5.  任务完成后，打开生成的HTML文件即可查看您的文献综述。
