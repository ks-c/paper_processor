# LitIntel Agent: AI 驱动的文献智能处理工具

`LitIntel Agent` 是一个基于 Python 和 Tkinter 开发的桌面应用程序，旨在帮助科研人员、学生和学者自动批量处理学术文献。本工具利用大型语言模型（LLM）的强大能力，从 PDF 文件或 PubMed 摘要文本中提取关键信息、进行翻译和总结，并将结果整理输出到结构化的 Excel 文件中。

这个脚本是在 [Google Gemini 2.5 Pro](https://deepmind.google/technologies/gemini/) 的协助下开发的。

## ✨ 功能特性

- **图形用户界面 (GUI)**: 提供一个简洁直观的操作界面，无需编写代码即可轻松使用。
- **两种处理模式**:
    1.  **PDF 文件夹模式**: 自动扫描并处理指定文件夹内的所有 PDF 格式的学术论文。
    2.  **TXT 文件模式**: 解析单个 `.txt` 文件，该文件应包含从 PubMed 等数据库导出的多篇文献摘要。
- **强大的 AI 信息提取**:
    - **元数据提取**: 自动识别并提取期刊名称、标题、作者、发表年份、摘要和 DOI。
    - **智能翻译**: 将论文标题和摘要翻译成中文，便于快速理解。
    - **核心内容总结**: 根据文件类型（PDF/TXT）生成不同详细程度的核心观点和结论总结。
- **高度可配置**:
    - 支持任何与 OpenAI API 兼容的语言模型服务（包括本地部署的模型）。
    - 允许自定义 API 密钥、服务地址 (Base URL) 和模型名称。
    - 自动保存和加载配置，方便下次使用。
- **实时监控与控制**:
    - 在界面上实时显示运行日志和 AI 返回的原始 JSON 数据。
    - 异步处理确保界面在任务运行时保持响应。
    - 提供“停止”按钮，可随时安全地中断批量处理任务。
- **结构化输出**: 所有处理结果都会被整齐地组织并保存到一个 `.xlsx` Excel 文件中，方便后续分析和管理。

## ⚙️ 工作流程

工具的工作流程非常简单：

1.  **输入**: 用户选择一个包含 PDF 论文的文件夹，或者一个包含 PubMed 摘要的 `.txt` 文件。
2.  **内容解析**: 程序读取文件内容。对于 PDF，它会提取全文文本；对于 TXT，它会按格式切分出每篇文章。
3.  **AI 处理**: 程序将提取的文本发送给用户配置的 AI 模型，并根据预设的指令（Prompt）要求模型返回包含元数据、译文和总结的 JSON 数据。
4.  **结果整合**: 程序解析 AI 返回的 JSON 数据。
5.  **输出**: 将所有文章的处理结果汇总，并生成一个结构化的 Excel 表格。

## 📦 安装与依赖

要运行此脚本，您需要 Python 3.7 或更高版本。

1.  **克隆或下载代码库**:
    ```bash
    git clone [您的代码库URL]
    cd [代码库目录]
    ```

2.  **安装所需的库**:
    建议创建一个 `requirements.txt` 文件，内容如下：

    **requirements.txt**
    ```
    pandas
    openai
    pypdf
    ```
    然后通过 pip 安装它们：
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 如何使用

1.  **运行脚本**:
    ```bash
    python your_script_name.py
    ```
    *(请将 `your_script_name.py` 替换为您保存的脚本文件名)*

2.  **配置 AI 服务**:
    - **API 密钥**: 填入您的 AI 服务提供商的 API Key。
    - **服务地址**: 填入 API 的 Base URL。例如，OpenAI 官方为 `https://api.openai.com/v1`。如果您使用本地模型或其他云服务，请填入对应的地址。
    - **模型名称**: 点击“刷新”按钮从服务地址获取可用的模型列表，然后选择一个。您也可以手动输入模型名称。
    - **Max Tokens**: 根据模型的上下文长度限制，设置一个合适的返回 Token 上限。

3.  **选择输入与输出**:
    - **输入路径**:
        - 点击 **"PDF文件夹..."** 选择一个包含 `.pdf` 论文的文件夹。
        - 或者点击 **"TXT文件..."** 选择一个包含多篇摘要的 `.txt` 文件。
    - **输出文件**: 程序会自动根据输入路径生成一个默认的输出文件名 (`summary_output_日期.xlsx`)。您也可以点击 **"另存为..."** 自定义输出路径和文件名。

4.  **选择任务**:
    - 勾选 **“翻译标题和摘要”** 来启用翻译功能。元数据提取和内容总结是默认启用的核心功能。

5.  **开始处理**:
    - 点击 **“开始处理”** 按钮。
    - 您可以在下方的“运行日志”和“AI实时返回”窗口中查看任务进度。
    - 如果需要提前终止，可以点击 **“停止”** 按钮。

6.  **查看结果**:
    - 任务完成后，程序会提示结果已保存。前往您设定的输出路径，用 Excel 打开生成的文件即可。

## 📄 输入文件格式说明

-   **PDF 文件夹**: 只需将所有需要处理的 `.pdf` 文件放入一个文件夹内即可。
-   **TXT 文件**: `.txt` 文件需要遵循特定的格式，即每篇文章以数字、点和空格开头（例如 `1. `、`2. `）。这是 PubMed 等数据库导出摘要时常见的格式。示例如下：

    ```
    1. [Article Title 1]
    [Authors 1]
    [Journal Info 1]
    [Abstract 1]

    2. [Article Title 2]
    [Authors 2]
    [Journal Info 2]
    [Abstract 2]
    ```

## 🔧 配置文件

程序会在首次关闭时在脚本所在目录创建一个 `config.json` 文件，用于保存您的 AI 配置。这样您下次打开程序时就无需重新输入。

**config.json 示例:**
```json
{
    "api_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "base_url": "[https://api.openai.com/v1](https://api.openai.com/v1)",
    "model_name": "gpt-4-turbo",
    "max_tokens": 8000
}
